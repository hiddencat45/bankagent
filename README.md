# 有度 · 银行 AI 智能体

PySide6 本地桌面银行模拟应用。普通表单与 AI 共用业务服务、确认和 SQLite 账本。模型理解请求并提出工具调用，服务端决定对象归属、授权、资金规则和执行结果。没有接入真实银行或真实资金。

账户与认证更新（2026-10-27）：普通卡一账户一卡；旧账本升级为v3，原余额留第一张主卡所在账户，其他卡迁至零余额账户，原流水/回执不改。高风险转账现在提供“前往模拟认证”入口，认证成功后继续原确认，真实银行认证仍未接入。升级前请关闭旧应用再重开；不要同时运行旧服务写同一账本。详情及失败案例见[交付核对](docs/交付核对.md)。日常账本本轮未直接改写，升级在新版首次打开原账本时发生。

2026-10-27 冻结规则修正：冻结付款卡同时禁止关联账户转出（含单笔、本人账户间及批量）；准备前说明原因，执行前再次核对，模拟认证不能绕过。解冻恢复转出；收款不受此次规则影响。

## 快速启动

Windows、Python 3.10，PowerShell 中运行：

```powershell
git clone --branch main https://github.com/hiddencat45/bankagent.git
cd bankagent
.\scripts\setup-desktop.ps1
.\start-desktop.cmd
```

默认 `start-desktop.cmd` 现在打开账户概览、转账和交易记录，右下角半透明悬浮球展开 AI；其他业务在“账户与卡”菜单。`start-desktop-preview.cmd` 是同一布局的兼容入口；`desktop/app.py --legacy` 可打开旧布局。应用自动管理本地服务，无需打开浏览器。仍是依赖 Python 的源码启动版；本轮复用了现有虚拟环境，未冒称在全新电脑完成安装验收。

C 方案界面调整（任务分支，尚未合并）：左下账户卡显示当前真实账户名称，点击“切换账户”选择服务端提供的账户；下方客户入口切换受控演示身份。右上保留会话状态、刷新和“更多→重新连接默认演示客户”。选择后直接切换，待确认或结果待核对时禁用；账单、付款账户和 AI 共用原有会话。实际截图与复演见[桌面应用](docs/桌面应用.md)。

正式自然语言体验需要 `BANKAGENT_MODEL_API_KEY`、`BANKAGENT_MODEL_BASE_URL`、`BANKAGENT_MODEL_NAME`；配置说明、独立演示账本与安全重开见[复演指南](docs/复演指南.md)。未配置模型时显示“离线规则”，只适合固定表达和普通表单演示。不要把密钥、运行数据库或原始诊断日志提交仓库。
