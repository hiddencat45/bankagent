# 有度 · 银行 AI 智能体

基于 PySide6 的本地模拟银行应用，支持对话查询和需确认的银行操作。用户任务与业务数据一致性是交付依据；模型只提出候选，归属、授权、资金规则和执行结果由后端决定。

## 打开与使用

Windows、Python 3.10、PowerShell；使用仓库虚拟环境。

```powershell
.\scripts\setup-desktop.ps1
.\start-desktop.cmd
```

桌面会启动本地服务并在退出时清理服务，强制绑定本机访问。当前仍是依赖 Python 的源码版。详细说明见 [桌面应用](docs/桌面应用.md)。

**已知启动阻断：**2026-10-27 对 `a5b2008` 的测试中，默认数据目录写入报 PermissionError，默认 LocalService 启动失败；使用独立可写账本路径可运行。这是特定机器的已知问题，不声称所有机器都会失败，也不能以测试通过代替修复。

可显式指定一个已有、可写目录内的账本文件，再启动桌面：

```powershell
$env:BANKAGENT_DB_PATH = "C:\你的可写目录\bankagent.sqlite3"
.\start-desktop.cmd
```

该示例需替换真实路径。已有账本应继续使用原路径；更换路径会打开另一份账本，不会迁移原数据。默认路径为 `%LOCALAPPDATA%/BankAgent/bankagent.sqlite3`；数据、重置和重启语义见 [本地持久化](docs/本地持久化.md)。不要用重置处理启动失败。

可复现输入：“最近钱花在哪里了”→“只看餐饮”→“列出超过一百的”；“给张伟转40元”→核对确认卡→取消或确认。实际金额取决于当前账本。高风险 RED 操作的独立认证未接入，当前只能取消，不能声称已经完成强认证。

## 模型与开发入口

模型配置读取 `BANKAGENT_MODEL_*` 环境变量；桌面还会补读 Windows 当前用户环境。不要把密钥写入仓库、日志或聊天。

| 配置 | 代码默认值 / 行为 |
|---|---|
| BANKAGENT_MODEL_API_KEY | 无；配置模型需要提供 |
| BANKAGENT_MODEL_BASE_URL | https://api.deepseek.com |
| BANKAGENT_MODEL_NAME | deepseek-flash；这里只描述代码默认值，不是供应商当前型号清单 |
| BANKAGENT_MODEL_TIMEOUT | 20 秒，范围大于 0 且不超过 120 秒 |
| BANKAGENT_MODEL_MAX_TOKENS | 512 |
| BANKAGENT_MODEL_THINKING | DeepSeek 地址默认 disabled |

相关配置全空时为离线规则；配置不完整时启动报错，不静默冒充真实模型。`create_demo_app` 同时装配候选模型、只读工具模型及润色模型。`GET /health` 不主动请求供应商，只是本地状态检查。最终自然语言不是授权或账务事实，金额和结果以业务数据为准。

```powershell
.\scripts\serve-api.ps1
# 或启动保留的网页开发工作台（不是最终产品形态）
.\.venv\Scripts\python.exe -m uvicorn frontend.dev_app:create_app --factory --app-dir src --host 127.0.0.1 --port 8021 --workers 1 --no-access-log
```

开发 API 未设置 BANKAGENT_DB_PATH 时使用内存账本，设置后使用 SQLite；每个服务仍使用内存会话和 Checkpoint，单进程运行，不启用多 worker。普通重开不清 SQLite；显式 `/demo/reset` 会恢复基线并使旧会话与挑战失效。

接口与场景依据见 [场景约定](docs/场景扩展与分工.md)、[账户与借记卡](docs/账户与借记卡.md) 和 [真实 Agent 查询回路](docs/真实Agent查询回路.md)。旧教学 `bank_agent_graph.py` 的 float 与固定口令只用于历史示例，不是新业务入口。
