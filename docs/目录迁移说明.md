## 导入与启动

代码统一使用 bankagent.agent、bankagent.banking、bankagent.api 包，不保留旧顶层模块别名，避免同一个模块被加载两次而产生两套后端状态。函数签名与 HTTP/SSE 协议不变。

- 测试：仓库根目录运行 `.\scripts\check.ps1`；pytest.ini 配置 `. src` 和 tests。
- API：`.\scripts\serve-api.ps1`，内部使用 `bankagent.api.server:create_demo_app --app-dir src`。
- 工作台：根目录执行 `.\.venv\Scripts\python.exe -m uvicorn frontend.dev_app:create_app --factory --app-dir src --host 127.0.0.1 --port 8021 --workers 1 --no-access-log`。
- 教学示例：根目录执行 `.\.venv\Scripts\python.exe -X utf8 src/bankagent/agent/bank_agent_graph.py`。
- 自定义 Python 调试脚本：先设置 `$env:PYTHONPATH = "src"`，或由自己的入口加入源码路径；不要在内部业务模块中动态补路径。
