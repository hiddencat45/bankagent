# 理财对话问卷与匹配规则（2026-11-01）

本轮按用户明确要求改为AI对话收集需求、优化匹配并保留表单，比赛提交包继续暂停。仅修改产品代码、开发说明及验证记录，不修改正式提交材料。基于产品池扩充PR #97。

## 用户流程

1. 首次进入理财且无有效需求时打开有度对话；也可主动点击“和有度聊聊需求”。已有需求不会强迫重填，先带入已确认内容再补问缺项。
2. 用户自由描述金额、预留资金、负债、用钱时间、亏损接受度、经验、生活影响和偏好。一次可以回答多项；服务端只追问仍缺少的内容。常见问题提供快捷回复，不自动选答案。
3. 大致期限转换为具体截止日期；明确日期继续确认能否提前赎回。“仅低风险”仍需明确是否接受本金亏损。不能承受亏损、借款理财或资金影响生活还款时提前说明，未填完也不会强迫继续。
4. 可以修改已提供信息。降低预算保留其他答案；提高预算时重新确认预留资金与生活影响。最后展示完整摘要，由用户确认保存，修改后的旧确认失效。
5. 对话保存成功后直接发起只读匹配，未申购、未扣款。表单保存后的现有“查看匹配产品”入口保留。

表单位于产品页“用表单修改”及“我的需求”，保留全部已确认值。明确日期优先，手动编辑相对天数会清除旧日期，保存前重新核对。无模型配置时明确显示离线规则，使用表单；模型出错不伪装成成功或自动放宽条件。可以关闭助手浏览产品，未保存的对话草稿不跨应用重启恢复。

## AI与服务端职责

AI通过`update_wealth_needs`提取当前用户表达的部分字段；服务端校验金额、日期、枚举，按用户、账户、对话隔离草稿，复用已保存需求，生成下一问或交给已有`SAVE_WEALTH_PROFILE`准备流程。问题及快捷选项是受控模板，自由语言理解使用真实模型，并非声称整段话均由模型自由生成。

草稿不写入账本。取消清理未执行任务；完成收集仍需既有确认，确认后的推荐只读。金额继续用整数分或Decimal。模型不提供身份、授权或风险评级，也不能直接申购。对话只询问本次可投资金额；确认资金已预留后，兼容字段`free_cash_minor`记录本次确认可用的额度，不推断用户全部资产或银行余额。

## 匹配规则v2

| 情形 | 处理 |
|---|---|
| 必要支出、借款或还款压力、亏损影响生活、预算不足、期限不够、不能承担本金亏损 | 明确不匹配；原因来自后端 |
| 亏损态度不明、备用金或生活影响未确认 | 待补充；不能据此模拟申购 |
| 仅低风险，但未确认接受本金亏损 | 待补充，不把低风险当保本 |
| 固定日期，未确认日期或提前赎回 | 待补充，不再一刀切排除 |
| 必须当天到账 | 能力尚未核实，不承诺满足；显示待核实 |
| 无经验 | 提示了解非保本和赎回限制，不单独决定R1或R2 |
| 仅低风险且确认可接受亏损 | 本演示仅比较管理人R1；不是银行正式测评 |
| 明确接受小幅亏损或波动 | 允许比较产品池中的R1/R2，其他约束仍须满足；不承诺R2损失幅度 |

用钱日期按保存时固定的日期计算剩余天数，查询或演示推进不会重置成“从今天起再等N天”。旧问卷只读兼容：从原记录日期与期限计算截止，不写回、不替用户改变答案；旧“固定日期”回答在对话中仍补问具体日期。新的表单准备阶段也把相对期限固定到确认参数，避免确认期间日期变化。

初筛与比较分组分开：

- 风险优先：按管理人风险、最低持有期比较，同条件并列。
- 流动性优先：按最低持有期、风险比较；明确不把持有期短解释为到账更快。
- 综合比较：从现金管理、30天及以内、30天以上三组中展示通过初筛的代表安排，最多每组一项；同条件按产品库稳定顺序取代表，不能解释为组内收益更高或更优。其余保留在“其他备选”。

“优先比较／其他备选”只影响展示，申购继续单独复核资格、额度、余额、确认和认证。没有统一收益评分，不按七日年化与成立以来年化直接排序，也没有虚构回撤、收益预测或资产配置建议。所有正常到账计算仍是本地演示日历，不代表真实渠道可按期到账。

## 契约与兼容性

使用`contract/wealth-conversation`分支；用户已明确授权该方案，不另行重复征求实现许可。原10个需求字段和已有操作保留，新增可选`need_on`、`early_redemption`、`reserve`、`impact`、`loss_acceptance`；亏损和收入枚举增加明确的“不确定”等回答。新模型工具仅进入现有准备—确认流程，不新增资金操作。

需求记录增加`anchor_day`，查询增加`needs_deadline`；筛选项增加`match_status`（matched/review/excluded）、notes、pending_reasons、remaining_days、comparison_group、preference_reason。旧eligible保留，只有matched才为true。旧问卷不自动迁移；新的筛选规则对旧数据也生效，因此旧“仅低风险”或“固定日期”的答案可能需要补充。

真实收益与合同资料沿用[产品池核验](微众代销产品池扩充.md)，本轮不更新收益快照。没有新增依赖或修改银行安全分级。
