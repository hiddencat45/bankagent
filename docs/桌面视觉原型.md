# 原生桌面视觉原型

对应实施方案第 6.2 节的第一步。此原型只验证布局和交互方向，不替换当前业务窗口，不连接模型、服务或数据库。所有金额、联系人和交易均为明确标注的示例。

## 设计方向

- 深绿色侧边导航、浅色业务内容、白色内容卡片，主按钮与普通操作区分。
- 账户概览突出当前账户、余额和近期交易。
- AI 位于可收起的右侧面板；原型只展示示例回答。
- 转账从同一表单填写信息，进入独立确认区；返回修改保留输入，结束预览不产生交易。
- 账单、卡包、理财独立页面尚未制作，其导航明确禁用并标为待预览。

## 启动与后台截图

在仓库根目录使用已有桌面依赖：

```powershell
.venv/Scripts/python.exe desktop/ui_prototype.py
```

启动后可切换账户概览与转账、收起助手、查看示例查询、修改转账信息、核对及结束预览。正式业务入口仍为 start-desktop.cmd。

不占用屏幕地生成原生控件截图：

```powershell
.venv/Scripts/python.exe desktop/ui_prototype.py --render .desktop-tmp/ui-preview
.venv/Scripts/python.exe desktop/ui_prototype.py --render .desktop-tmp/ui-preview-small --width 1024 --height 768
```

输出 overview.png 与 transfer.png。原型最小逻辑窗口为 1024×768，默认 1280×840；Windows 离屏模式显式加载系统微软雅黑字体。截图属于本地预览输出，不作为已完成实际屏幕验收的证据。

## 后续实施与边界

方向经试用反馈调整后，将布局接入现有 BankWindow 的会话、查询及服务端确认机制；业务页面需要真实数据接口，不能把此原型示例搬成正式数据。接入时继续保留重试、防重复执行及账户切换规则。

本轮不包含正式图标、独立安装包、全部业务页面或真实模型接入。100%/125%/150% 系统缩放和实际窗口键盘使用仍需后续人工验收，离屏渲染不替代这些检查。
